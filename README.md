# sort_report
排序法
 https://shunhsincheng.github.io/sort_report/
五個排序法介紹
說明五種排序法的基本原理與操作方式。
複雜度分析
分析各排序法的時間複雜度與空間複雜度。
數據模擬
以程式實作五種排序法，比較排序 n 個數所需時間。
結果呈現與比較
以表格或圖表整理實驗結果，並比較不同排序法的效能差異。
心得與結論
根據理論與實驗結果，提出個人觀察與心得。
基本要求
報告需同時包含理論說明與實驗分析
實驗資料量需有不同規模，觀察排序時間隨 n 增加的變化
內容應條理清楚，圖表完整，結論具體
建議報告架構
前言、排序法原理、複雜度分析、實驗設計、結果比較、心得結論。
